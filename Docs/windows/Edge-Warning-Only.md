# 崖のRaycastは警告のみ

2026-09-13のユーザー指定により、groundPresent=false、左右の端near/very_nearを理由に歩行を停止しない。Raycast観測自体は維持する。

Bridgeの操作・計画・距離移動の停止判定から崖/足場切れを除外。UnityのFlyTerrainTraversalでも同じ地形条件のSafetyHoldを除外し、着地点がない脚は通常の歩行目標を使い続ける。接触は捏造しない。

新鮮な危険観測を受けるとGPT-Liveへ「もうすぐ落ちそうです。」の発話を依頼する。繰り返し通知せず、地面ありかつ左右safeを観測してから再通知可能になる。旧世代・古い観測・会話専用モードは通知対象外。

前方障害・身体姿勢異常・通信や観測の欠落・ユーザーのSTOP・操作期限は既存の処理を維持する。崖を歩き越して落下することを許す変更であり、落下自体の物理やゲーム側の落下判定は変更しない。

Bridge関連の単体テスト127件成功。実際の崖への接近と音声発話の確認は別途必要。
