# English presentation and bounded course guidance

Updated September 15, 2026. This records the current implementation scope; it is not evidence that the latest build has passed live acceptance.

The product interface and fly replies use English. Shared Japanese protocol and input compatibility remain available internally. The packaged instructions no longer promise a language switch. On launch, the title waits for the required connections before Start becomes available; the swatter timer belongs to gameplay.

The fly answers questions in ordinary first-person language while the current movement remains active. Speaking, interrupting narration, or asking a question does not itself cancel, replace, or restart movement. Explicit stop requests and existing safety conditions still apply. Technical observations remain grounding context, rather than a script to read aloud. A tired or focused expression is a character impression, never a diagnosis or a measured emotional state. Routine visible stillness and movement do not require unsolicited narration.

For a finalized movement request that remains unclear, the Bridge may consult fresh Unity course guidance and try a short action through the existing Brain path. It does not invent an unseen route, map a question into movement, or derive commands from its own narration. Missing or stale guidance does not justify guessing. The assistance retains bounded duration and existing control ownership, generation, freshness, cancellation, and safety checks. Reaching the goal or avoiding every hazard is not guaranteed.

The current unclear-request fallback lasts at most six seconds, or the configured action limit if shorter. It can update the active action from a turn to forward movement as fresh route guidance changes, after application of the preceding request and at least 0.4 seconds since submission. Updates retain the original deadline; they do not create an indefinite autopilot. A new player command replaces the fallback. STOP, manual ownership, explicit left/right requests, and existing safety checks take priority.

The latest Unity assistance uses a baseline lane correction of 0.3, or 0.5 for a matching explicit turn, with a total cap of 0.65 and gradual changes. It never steers against the requested side. Existing neural-driven activity is required. Translation is eased while the body faces away from the route or its current forward corridor lacks support; no backward movement is added. Route recovery uses the next supported junction and a dedicated entry point at the book-to-detour connection. Body-width corridor samples and swept foot positions, including foot rims, distinguish a supported turn from an unsupported forward step. These changes are implementation work under current build/live validation, not a new passing result. See [assistance details and historical evidence](Demo-Safety-Assist.md).

Unity course guidance is explicit game assistance. It is separate from the fly's local observational dialogue and is not evidence that MaleCNS sees a route, has learned it, or intends to follow it. Actions still pass through stimulation, raw neural output, the existing decoder, and body control; the guidance does not directly set motor values.

The English local-observation fix covers ordinary surfaces, unknown directions, body descriptions, and hazard, memory, and discovery announcements. Presentation checks passed 23 existing and added unit tests covering bounded neural summaries, narration scheduling, and local visual observations. A broader set of 138 protocol/presentation tests passed. Those tests do not establish real Brain movement or voice quality.

## Final natural-assist validation

The revised release passed one actual full-course Windows Brain trial: `full_course_live_brain_clear`, 254.65 seconds, zero deaths, actual goal and reveal complete. Live source and fresh Brain were maintained throughout playing; raw ready remained false. Player exceptions: 0; exit code: 0; forced cleanup: false; remaining owned processes: 0. The test used normal scripted player text, no pose/goal relocation or motor injection, and no physical microphone. This demonstrates one successful assisted run, not universal success or a human assessment of naturalness.

The final swept-turn rule requires at least four supported feet spanning both sides and front/back, rather than every foot rim. Forward uses the sampled body-width support corridor instead of a redundant edge-warning veto. Explicit directions and STOP still win. Control regression tests: 47 passed.
