# プロトタイプの1シーンUI

更新日: 2026-09-14

今回のプロトは `Assets/BlindSugarRunPrototype/BlindSugarRunPlay.unity` の1シーン構成とする。TitleScreen は起動時に同シーンへ自動生成される全面UIであり、開始ボタンでシーンを読み込まない。旧タイトルシーンはビルド対象外。

起動 → タイトル → 初回のみ操作説明 → プレイ。タイトル・説明中は時間と音声操作の自動開始を止める。説明完了後、既存の実Brain接続・安全条件を満たしてから身体操作が再開する。説明を閉じても接続不良を無視して時間を再開しない。

操作説明の完了を PlayerPrefs `Flylingual.Prototype.InstructionsCompleted.v1` に保存する。説明を読み終える前に終了した場合は、次回も表示する。保存は端末・OSユーザー単位。リトライ時にタイトルを再表示しない。

右上の設定ボタンは常時表示し、日本語・Englishの表示切替はタイトル・説明・プレイ・結果表示中にも可能。プレイ画面の入力内容や設定編集中の値はUIの再生成で失わない。会話の設定変更は既存の停止中適用ルールに従い、表示言語ボタンから会話中の設定要求を無条件には送らない。起動時の会話言語は既存の選択言語同期処理を使用する。

ビルド入口は1シーンのみ返却する。Editorのスクリプト読み込み後、非Play時にビルド対象とPlay開始シーンを同シーンへ設定する。既存シーンを開き直したり、未保存のシーンを保存したりはしない。

## 確認状況

Unity 6000.5.9f1の既存参照・コンパイラーによる外部C#コンパイルを確認。Editorへの接続ができず、稼働中のEditorの用途を確認できないため、その停止・再起動、実Brain接続テスト、画面の目視、Player再ビルドは未実施。外部コンパイルは実行検証の代替ではない。
