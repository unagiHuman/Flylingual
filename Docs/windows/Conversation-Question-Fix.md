# 質問・自由会話の応答修正

2026-09-13。操作用のResponsesフォールバックは、localの一部のclarifyを再解釈する機能であり、雑談や状態質問をResponsesへ渡す機能ではない。自由会話の担当は実OpenAI GPT-Liveである。

不具合はTranscript経路でkind=questionをclaimした後、観測や返答をLiveへ送らず終了していたこと。さらに音声promptが説明を含む全発話を一言・一文へ制限していた。

修正方針は、状態質問に現在の観測を返してLiveが回答できるようにし、移動指示の変更と分離すること。操作の相づちや自発的な台本は短く保つが、質問・雑談には通常2〜4文で答える。身体動作はBrainの受付だけで断定しない。一般知識の回答に局所センサーの情報を無理に当てはめない。

詳細な自由会話用Responsesエージェントは今回追加しない。質問の消失を直すことと、高度な調査・推論のための追加バックエンドは別の変更として扱う。
