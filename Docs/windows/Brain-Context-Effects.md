# 脳表示のゲーム状況エフェクト

脳の点群の色は実測表示を維持し、周囲のリングだけでゲーム状況を表す。感情・快不快の神経指標ではない。画面の「ゲーム演出」表示とツールチップで区別する。

- 探索中：淡い緑のゆっくりした脈動。Playing・操作有効・fresh Brain・非ポーズ時のみ。安全を保証する表示ではない。
- ハエたたき予告中：赤い速い脈動と危険ラベル。WarningActiveを参照する。
- Goal / Reveal：金色の広がるリング。
- タイトル・接続待ち・停止：静かな待機表示。GameOverは挑戦終了。Retry後は新しいSessionを参照する。

表示専用。Brain入力・motor・物理・ゲームの勝敗は変更しない。崖の検知による演出は今回含めない。
